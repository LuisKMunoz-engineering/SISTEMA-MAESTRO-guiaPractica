# Guía Práctica de Preparación · Sistema Maestro

Herramienta interactiva para que los aspirantes a vacantes docentes y directivos docentes en el marco de la **Resolución MEN 003593 de 2024** (y su anexo técnico) preparen y organicen sus soportes documentales antes de postularse.

---

## 🎯 Funcionalidades Principales

1. **Ruta de Preparación:** Guía paso a paso en 6 momentos clave antes de la postulación.
2. **Lista Personal de Verificación:** Checklist interactivo clasificado por tipo de documento y grupo de edad (con persistencia en `localStorage`).
3. **Validador de Archivos PDF:** Comprobación técnica básica en el navegador del tipo de archivo y límite de peso (máximo 1 MB por soporte).
4. **Guía de Certificados:** Lista de chequeo para verificar requisitos formales de certificaciones de educación, experiencia y vínculo territorial.
5. **Criterios y Tablas de Puntuación:** Visualización interactiva de la tabla general y tabla específica de ponderación.
6. **Simulacro Interactivo:** Cuestionario de práctica con retroalimentación inmediata sobre las reglas del proceso.

---

## 🚀 Despliegue en GitHub Pages

Este proyecto es una aplicación web estática (Vanilla HTML5, CSS y JavaScript). No requiere servidores ni procesos de compilación.

Para activarlo en GitHub Pages:
1. Ir a **Settings** > **Pages** en este repositorio.
2. En **Build and deployment > Source**, seleccionar `Deploy from a branch`.
3. Seleccionar la rama `main` y la carpeta `/(root)`.
4. Guardar los cambios. La aplicación quedará disponible en:
   ```
   https://<tu-usuario>.github.io/<nombre-del-repositorio>/
   ```
